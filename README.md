# RIFT PROTOCOL

ブラウザで遊べる、オリジナルのシングルプレイヤー・タクティカルFPS。Three.js による3Dの戦場で敵部隊を排除し、3ラウンド先取を目指します。VALORANTに着想を得ていますが、名称・マップ・モデルは独自のもので、公式作品ではありません。

## 起動

Node.js 20.19+ または 22.12+、WebGL対応のデスクトップブラウザとマウス・キーボードが必要です。

```sh
npm ci
npm run dev
```

ビルド: `npm run build` / ビルドの確認: `npm run preview` / ルールのテスト: `npm test`

## 遊び方

「作戦を開始」をクリックするとマウスがゲーム画面に固定されます。敵をすべて倒すとラウンド勝利。HPが0になるか90秒経過すると敗北。先に3勝した側が勝利です。後半ほど敵が増えます。各ラウンドでHP・弾薬・アビリティがリセットされます。

| 操作 | キー |
| --- | --- |
| 移動 | WASD |
| 視点 | マウス |
| 射撃（長押しで連射） | 左クリック |
| 精密照準 | 右クリック長押し |
| リロード | R |
| 索敵パルス（5秒間表示、18秒クールダウン） | Q |
| HPを45回復（25秒クールダウン） | E |
| スプリント（射撃不可） | 左Shift |
| 一時停止・マウス解除 | Esc |

遮蔽物は弾も遮ります。頭部への命中は一撃、胴体は3発。近くの敵と索敵中の敵はミニマップに表示されます。サウンドは右上で切り替えられます。通信対戦・スマートフォンのタッチ操作には対応していません。APIキーや外部サービスは不要です。

## ブラウザテスト

`npm run test:e2e` で、実際の3D画面の起動・射撃・リロード・索敵・ポーズ・ヘッドショットを検証します。`/usr/bin/chromium` があればそれを利用します。ない環境では事前に `npx playwright install chromium` を実行してください。
